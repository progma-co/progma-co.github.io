    Contribute

    This map is corrected in public.

    The data lives in Progma's public GitHub repository, one file per value-chain node. Anyone can suggest a change; every change is reviewed before it goes live. The atlas is re-scanned every fortnight against what was suggested and what moved in the market.

    Suggest a company or correctionSee the data on GitHub
    How it works
    1. Use “Suggest” on any box or listing. It opens a short form on GitHub.
    2. Companies can claim their listing from their organisation's GitHub account to keep it accurate.
    3. Developers can edit the node file directly in a pull request; an automatic check validates it.
    4. Fork the repository to run your own version. The data is CC BY 4.0: credit Progma and link back.
